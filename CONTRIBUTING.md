# Contributing to OMP.jl

We welcome any form of contributions to OMP.jl, and more generally to projects of the [Julia-OpenMP Organization](https://github.com/Julia-OpenMP).

## Bug reports, Feature Requests

Please open issues at [https://github.com/Julia-OpenMP/OMP.jl/issues](https://github.com/Julia-OpenMP/OMP.jl/issues)

## Pull requests
We strongly recommend any external contributors to reach-out with the team first ([Contact](https://github.com/Julia-OpenMP#contact)).
