Directives

OMP.Frontend.@pragma — Macro
@pragma "omp directive [clauses...]" [associated code]

An OpenMP directive, written as in C/C++/Fortran, followed by its associated code if any:

@pragma "omp parallel num_threads(4)" begin
    ...
end

@pragma "omp parallel for reduction(+: s) schedule(dynamic, 4)" for i in eachindex(x)
    s += x[i]
end

@pragma "omp task depend(in: a) depend(out: b) if(n > 10)" begin
    ...
end

@pragma "omp barrier"

Expressions in clauses are Julia code referring to the variables of the caller.

Directives that are valid Julia syntax, i.e. without Julia keywords (for, if, do, begin, local, ...), may also be written without a string: @pragma omp task depend(in: a) begin ... end.

Syntax errors are reported at macro expansion time as OpenMPSyntaxErrors.

source
OMP.Frontend.@omp — Macro
@omp "directive [clauses...]" [associated code]

Same as @pragma "omp ...", e.g. @omp "parallel for" for i in 1:n ... end.

API routines

The OpenMP API of omp.h (omp_get_num_threads(), omp_lock_t, ...) is exported by OMP, from omp-abi (see the README).

OMP.has_routine — Function
OMP.has_routine(name) -> Bool

Whether the OpenMP runtime selected by omp-abi provides the OpenMP API routine name (e.g. :omp_get_num_teams_dim): the API follows the latest OpenMP specification, which runtimes may not implement yet. Calling a routine that the runtime lacks aborts.
