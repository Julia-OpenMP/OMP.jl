# Releasing OMP.jl

OMP.jl is distributed through the
[Julia-OpenMP registry](https://github.com/Julia-OpenMP/Registry), together with
`OMPABI_jll`, the prebuilt omp-abi library, which is built here with
[BinaryBuilder](https://docs.binarybuilder.org) rather than by Yggdrasil.

All commands run from the root of OMP.jl, on Linux, with Julia 1.13.
```bash
julia --project=contrib -e 'using Pkg; Pkg.instantiate()'
```

## 1. Release omp-abi binaries (`OMPABI_jll`)
In `yggdrasil/O/OMPABI/build_tarballs.jl`, set the omp-abi commit and bump `version`, then:
```bash
# try a build (products in contrib/yggdrasil/O/OMPABI/products, JLL in ~/.julia/dev/OMPABI_jll)
julia --project=contrib contrib/yggdrasil/O/OMPABI/build_tarballs.jl --verbose --deploy=local x86_64-linux-gnu
rm -rf ~/.julia/dev/OMPABI_jll   # otherwise reused, instead of a clone, by the deploy below

# build every platform, push the JLL to github.com/Julia-OpenMP/OMPABI_jll.jl and
# upload the tarballs to a GitHub release of it
GITHUB_TOKEN=<token> \
    julia --project=contrib contrib/yggdrasil/O/OMPABI/build_tarballs.jl --deploy=Julia-OpenMP/OMPABI_jll.jl
```
Its content is entirely generated by BinaryBuilder, never edit
it: the `OMPABI_jll` package (`Project.toml`, `Artifacts.toml` pointing to the release
tarballs, `src/`), and one GitHub release per version holding the tarballs.

Then register the new version (step 3), and bump the `OMPABI_jll` compat of OMP.jl if needed.

## 2. Create the registry (once)
Create an empty `Julia-OpenMP/Registry` repository on GitHub, then (this also installs the
registry in your depot, where `register` finds it by name):
```julia
using LocalRegistry
create_registry("JuliaOpenMP", "git@github.com:Julia-OpenMP/Registry.git";
                description="Julia packages of the Julia-OpenMP organization", push=true)
```

## 3. Register a version
```julia
using LocalRegistry
# OMPABI_jll: the clone left by the deploy of step 1
register(joinpath(homedir(), ".julia", "dev", "OMPABI_jll"); registry="JuliaOpenMP", push=true)
# OMP.jl: bump `version` in Project.toml first
register("."; registry="JuliaOpenMP", push=true)
```

## Moving to the General registry
1. Submit `yggdrasil/O/OMPABI/` to [Yggdrasil](https://github.com/JuliaPackaging/Yggdrasil):
   `OMPABI_jll` is then published and registered in General automatically.
2. Remove the `[sources]` section of OMP.jl's `Project.toml`, and register OMP.jl in
   General with [Registrator](https://github.com/JuliaRegistries/Registrator.jl).
3. Users drop the Julia-OpenMP registry; `pkg> add OMP` keeps working.
